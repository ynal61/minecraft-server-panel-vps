## 开服步骤：面板服 7 步，VPS 4 步

### MCSM 面板路线

1. 注册登录，进「游戏云 → 购买」，按人数和版本选配置。不确定就先 1 元试用。
2. 买完在「云产品 → 游戏云」点管理，进「重装 / 切换游戏」选服务端类型。教程推荐 Purpur；想上 Folia 多线程优化端也行，但要自己重装 Java 环境并上传核心，支持的插件也少。
3. 「信息与监控 → 管理面板」找到实例，点开机，等它跑完。
4. 公网 IP 的机器直接用公网 IP 进游戏。NAT 机器要做端口映射：外部端口一般随机生成，内部端口填实例上服务实际运行的端口，协议 MCJE 选 TCP、MCBE 选 UDP。
5. 复制地址发给朋友测试。进不去先查内网端口填对没有，再查外网端口是不是被占了。
6. 整合包场景：功能组 → 文件管理，上传服务端压缩包，解压到当前目录；打开 `server.properties`，把 `server-port` 的值改成刚才映射的端口；再打开启动脚本，把内容替换成新版本的启动命令，**文件名不要改**；回终端点启动。
7. 面板登录用「面板主账户 / 面板密码」，成品地址形如 `ni.rainplay.cn:33333`，以你控制台里显示的为准。

### VPS 路线

1. 远程桌面连接，IP **要带端口**输入，Windows 用户名一般是 Administrator。
2. 按服务端版本装 Java。
3. 上传服务端核心到同一目录，新建 `Run.cmd`，内容写 `java -jar 核心文件名.jar nogui`；Forge 服走 `@` 库方式。Linux 下写 `run.sh`，命令形如 `java -Xmx2G -Xms512M -jar 核心.jar --nogui`，`-Xmx` 是最大内存，`-Xms` 是最小内存。
4. 双击或执行脚本启动，控制台停住就能进；NAT 机器记得先映射游戏端口。

### 更新整合包时，哪些文件不能删

关服后，除了 `world` 文件夹和 `server.properties`、`ops.json`、`whitelist.json`、`banned-players.json` 这几个配置文件，其余可以清空，再上传新版服务端解压。面板服尤其注意别删启动脚本，它承载的是启动命令。

启动脚本要和版本对上。以 ATM10 为例，V5.5 对应 `21.1.219`，V6.6 对应 `21.1.224`，V7.0 对应 `21.1.228`，版本换了脚本里的路径没换，服务端起不来。

`server.properties` 里几个值得改的项：`max-players=20` 人数上限、`view-distance=7` 视距、`simulation-distance=5` 模拟距离、`online-mode=true` 正版验证、`white-list=true` 白名单、`spawn-protection=0` 出生点保护关掉。

## 几个容易卡住的地方

**面板服的天花板在群组服。** 单人服、小生存、纯净插件服都没问题，一旦想拆成登录服 + 资源服 + 生存服的群组架构，只能整台换 VPS，前面在面板上做的配置搬不过去。有群组规划的人，一开始就买 VPS 更省事。

**NAT 机器内外端口不一致时，必须同步改 `server-port`。** 这是最常见的“服务端明明开着，外网就是连不进”。映射时外部端口是随机的，服务端默认监听 25565，两边对不上就通不了。改完 `server.properties` 再重启。

**Java 版本别装错。** 按服务端版本来：1.8 到 1.12 用 Java 8，1.12 到 1.16 用 Java 11，1.16 到 1.20 用 Java 17 或 21，1.21 用 Java 21。另有旧教程以 1.17 为分界（以下 Java 8、以上 Java 17），1.16 到 1.17 这段两份说法不一致，以你下载的核心自己声明的要求为准。

**默认端口是 25565。** 论坛教程里出现的 25665 是笔误，照抄会连不上。

**国内禁 TCP 建站。** 教程里加粗重复了三遍的提醒，游戏云就拿来开游戏，别顺手搭网站。

**固定计费还是动态计费，两派说法。** 论坛两篇教程都推荐固定计费、全程火力全开；第三方整理则说动态计费适合白天没人、晚上才热闹的私人小服，按 CPU 实际占用收“电量费”，闲置时段几乎不花钱。开黑时间集中在晚上的，动态计费确实省；白天也有人挂机的，固定计费更可控。

**优先 Linux。** 整合包教程明确不推荐用 Windows 开服，系统自身占的内存和 CPU 更多，同样配置跑出来的余量更少。
